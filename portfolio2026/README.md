# Portfolio 2026 – Oriane Van Loo

Private interview portfolio. Two versions of the same page share one `img/` folder.

- `index.html` – original version, served at `/portfolio2026/`
- `revolut.html` – Revolut-styled version, served at `/portfolio2026/revolut.html`
- `img/` – images, logos and short silent videos (MP4 + WebM), used by both pages
- `robots.txt` and the `noindex` meta tags ask search engines not to index the pages

To update, replace the whole `portfolio2026` folder in the repository.
