Rome2Rio · 2024–2025

Hitch 2.0 design system

Rome2Rio had two separate design systems and dev stacks that had drifted apart. I unified them, defined a clear graduation path for components, and built token infrastructure that made future changes—like a typeface swap—trivial across both stacks.

Design systems Token architecture Cross-stack coordination

My role

Product Design Lead

Team

Engineering, product, brand

Outcome

95% adoption, 80% reduction in duplicates

The problem

Designers hunted across Figma files. Engineers couldn't find components quickly. Storybook mixed old and new versions with no clear path forward. Token naming didn't match between stacks. Every new feature meant rework. This wasn't just inconvenient – it was an organisational efficiency tax.

What I built

1
Single source of truth Unified Figma library replacing two systems, with naming conventions audited with engineering. Component showcase at /design-system/hitch-2-0 showing usage and code snippets.
2
Token system OKLCH + APCP colour model. Semantic tokens (e.g. color.action.primary) rather than primitives, so design intent was captured and theming became systematic.
3
Graduation path Six-step process: propose, validate, build, adopt, graduate, maintain. Same path works at any scale so teams know exactly where a component is.
4
Documentation Storybook with documented states. Usage notes, do's/don'ts, accessibility guidance. Clear migration paths for deprecated components.

"When I suggested switching from Roboto to Google Sans, the entire product's typography changed in a day with zero rework. That's what infrastructure thinking looks like."

How infrastructure compounds

Rome2Rio wanted to feel more approachable, so I suggested a typeface change. In a fragmented system, this would have meant hunting through dozens of Figma files, updating each one, hoping nothing broke, coordinating across stacks.

Because I'd tokenised typography early, it was trivial: one token update in Figma, and every component using that token updated automatically. The switch happened in a day with zero rework. That single token did months of compounding work – it unlocked the ability to make global changes easily, forever.

Results

95% Design team now uses Hitch for component decisions
80% Reduction in duplicate component versions in 60 days
→ Foundation for dark mode, iOS and Android extensions
